Installing

  • Windows 10 or 11: run the installer. It installs for you alone, with no administrator password.
  • Mac (macOS 11 or later): open the disk image and drag TUNAS into Applications. This build is not yet signed by Apple: run this once in Terminal, then open TUNAS:
    xattr -dr com.apple.quarantine /Applications/TUNAS.app
  • Android 9 or later (64-bit): open the downloaded file and allow installing apps from your browser or Files app. If Play Protect warns, choose More details, then Install anyway.
